# Severe Weather Operations

A browser-based severe-weather operations simulation game, developed from scratch.

## Current stage

The first prototype will focus on an interactive operational map, evolving simulated storms, and issuing/expiring practice weather products. All events and products are fictional simulations, not real forecasts or warnings.

## Stack

- HTML, CSS, JavaScript: game interface and interaction
- Python: planned diagnostics and scenario tooling
- Fortran: optional future numerical simulation core

## Run

Open `frontend/index.html` in a modern browser. No build step is required for the initial prototype.

## Project structure

- `frontend/`: browser game
- `python/`: future meteorological diagnostics
- `fortran/`: future simulation kernel
- `configs/`: scenario configuration
- `tests/`: automated tests
